# UniversalResourceTransferRedux

Beamed power/resource transmission in Kerbal Space Program.

## AI Usage disclosure:
### Mod concept
AI was not involved in creating the concept of beamed power transmission in KSP (neither was I, as this mod is descended from prior mods). Transmission of multiple different KSP resources and the concept of some resources being transmitted in physically identical (and thus logically safe to convert between) manners are, to my knowledge, my own ideas.

### Assets
No assets in this mod were created by AI.

### Final Code
Almost entirely typed by me. AI used to provide examples of some concepts that were new to me (interfaces, mostly). I estimate 10-20 lines of AI code in the mod's source code. Most of this will be in the code dealing with coordinate systems. AI was also used to convert handwritten notes to cleaner LaTex for the technical details. This latter I intend to revisit later, as back then I was unfamiliar with LaTex and now I am not.

### Coding Process
AI was used extensively during the planning phase of the code. I used it to brainstorm how to structure my code and pitched various performance improvements for it to evaluate. Once I settled on the implementation, it was written by me, as I consider this mod a learning project. All features were thought of and added by me, but I did ask AI for advice on UX as well as people on a modding Discord.

### Testing
All features of the mod that I tested were tested to the best of my abilities, and all bugs I am currently aware of were fixed. No buggy AI code was fixed via AI. Please report any bugs you encounter. 

### Documentation
I used AI to convert bullet points into prose, and then edited this text with relevant footnotes etc. I will revisit this only if the documentation feels unclear to some users. All content is verified by me to be true and applicable to the current release version of the mod.
